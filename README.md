# Drive North Cyprus (Kuzey Kıbrıs Yol Rehberi)

**Drive North Cyprus** is a curated road trip and travel discovery platform for Northern Cyprus. Crafted with insights from knowledgeable local guides, the platform helps travelers explore 41 handpicked driving routes, ancient castles, pristine Mediterranean beaches, and mountain villages across the island.

---

## Features

- **41 Curated Driving Routes:** Step-by-step itineraries featuring key waypoints, driving times, distance, difficulty ratings, and local insider tips.
- **Full Bilingual Support:** Complete Turkish (`/`) and English (`/en`) localization.
- **Interactive Route Maps:** Integrated GPS route maps and navigation links for every stop.
- **Northern Cyprus Driving Guide:** Crucial road advice, traffic rules (left-hand driving), documentation requirements, and local emergency numbers.
- **Modern & Responsive UI:** Clean luxury aesthetic with dark and light mode support, optimized for mobile, tablet, and desktop.

---

## Tech Stack

- **Framework:** [Next.js](https://nextjs.org/) (Static Site Generation / Export)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Icons & UI:** [Lucide React](https://lucide.dev/) & [Radix UI](https://www.radix-ui.com/)
- **Theming:** `next-themes`
- **Typography:** DM Sans & Outfit

---

## Getting Started

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Run the local development server:**
   ```bash
   npm run dev
   ```
   Visit [http://localhost:3000](http://localhost:3000) in your browser.

3. **Build static export for production:**
   ```bash
   npm run build
   ```
